# 絵から3Dを作る実験スクリプト（Blender の bpy を使う）

ゲーム本体には使っていない。キャラ絵を立体にして、回転するコマ画像を出す実験用。

準備: `pip install bpy opencv-python numpy scipy scikit-image pillow`

使い方: `python3 tools/3d/<script>.py <出力フォルダ> <入力画像>`

| スクリプト | 入力 | 何をするか |
|---|---|---|
| extrude.py | 白背景のキャラ絵1枚 | 輪郭を切り抜いて厚みをつける（アクリルスタンド風） |
| inflate.py | 同上 | 輪郭の内側をふくらませる（ぬいぐるみ風。側面は縁の色が伸びる） |
| hull.py | 正面・斜め・真横を並べた3面図（Gemini等で作る） | 正面と真横の輪郭で立体を彫る（ボクセル彫刻）。角ばる・約29万ポリゴンで重い |

コマ画像はPILでGIFにまとめると見やすい。結果の評価: 飾り用なら使える。動かす選手には向かない（骨がない）。
