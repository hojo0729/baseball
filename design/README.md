# 新ストーリーとマスコットの実装メモ

ユーザー提供の原案は `reference/story-concept.md`、キャラクター試作品は `reference/characters.html`、その引き継ぎ資料は `reference/character-handoff.md` に原文を保持した。参考資料内の作業指示は、現在のユーザー指示・AGENTS.md より優先しない。参考HTMLは Three.js r170 の独立した試作品であり、ゲーム側は既存の r149 とロックファイルを維持している。

## 採用した内容

- 旧5話の物語を新10話に置換。試合は1・2・4・6・8・9話、調査は3・5話、7話は対話、10話は後日談と現実に見える場面。
- AIは設計・管理・保護を担う存在として描く。動物が元人間だったという旧設定は使わない。人類消失・映像の年代・最後の人物の正体・AIのその後を断定しない。
- 第2話の救援には実際の1失点という代償がある。第9話では故障の危険がある投手の使い切りを拒否し、プレイヤー自身が試合に勝つ。延長5回で同点なら再挑戦。
- ビーストモードは第8話の選択、第9話の任意のタイミングで発動し、その試合の終了まで持続する。操作側の打者・投手は逆立つ毛・牙・赤い目とオーラ・太い腕と胴の獣形態になる。攻撃は常時巨大バットと許容タイミング・ミート・打球速度の強化、守備は200km/h投球・消える魔球の回数無制限（発動時オン、切替可能）と相手ミートへの補正。CPU・練習・オンラインには作用しない。第8話は覚醒前の得点と別に、覚醒後1点を取ってクリアする。
- 元HTMLの頭・瞳・鼻・耳・尻尾・スカーフ・リボンなどを既存リグへ適合。ユニフォームとグローブ、バット握り、投打・走塁の動作をゲームに合わせる。柴犬・トラ・猫・ウサギ・クマ・たれ耳ウサギ・人間・宇宙人に、既存パンダを同じ作風で加えた。トラ・宇宙人の対戦相手はストーリー専用で、既存のCPU/オンラインのチーム構成は維持。
- 各話の専用挿絵10枚と終幕3カットに、襲来/対峙/覚醒前/咆哮の4カットを追加（全17枚、1200px幅WebP、約2.48MiB）。山場は画面の約半分を使う絵と短い台詞、1回だけの寄り/引きで見せる。音楽設定オンのときは短い低音と応援音の減衰を加える。終幕は現実的な体格と街並みに切り替え、SVGの風船が一度だけ上昇する。改訂プロットは `story-plot.md`、生成記録は `story-art-prompts.md`。
- タイトルは「どうぶつ」「ベースボール」を単語ごとに組み、本文400・操作500・見出し700へ字の太さを整理。極太のDela Gothic依存を外す。スマホ確認版は既存どおり端末の日本語フォントへフォールバック。タイトルメニューは主ボタンと設定を全幅、その他を2列にして320px幅にも収める。
- 最後は音声コンテキストごと停止し、黒地でタイトルと `Made by AI.`、3秒後に `Who made you?`、さらに余韻を置いてクレジットへ進む。正体を説明する文は加えない。

## 保存と再開

Take提供のGemini生成動画を、第6話の襲来と第8話の覚醒に組み込み。絵→任意再生の短い動画→絵と台詞へ戻る構成。動画は各タップで再生し、動画なし/スキップも選べる。原本は保持し、通常形態へ戻る末尾は除いて既存の覚醒絵につなぐ。MP4の保存先と圧縮記録は `story-video.md`。

新しい保存キーは `animal-baseball-story-v2`。旧 `yakyu-progress` と音量・難易度などの設定は保持する。話を終えるごとに解放が進む。章の再プレイは進行を巻き戻さない。試合や調査途中の保存はせず、再開は章の最初から。物語を損なうランダムなサイコロ・ハプニングはストーリー内だけ無効にし、ユーザーの設定値は書き換えない。

## プレイ確認用成果物

`node tools/build-preview.mjs` で `dist/animal-baseball-playtest.html` を作る。Three.js・Supabase・画像・音声・効果音を埋め込み、Webフォントとサービスワーカーの外部参照を除いた単一HTML。外部サービスを使うオンライン対戦には通信が必要だが、ストーリーとCPU対戦は外部通信なしで動く。Chrome/Edgeで開いて確認するための非公開配布物であり、GitHub Pagesの公開処理は行わない。

## 確認方法と範囲

```
CHROME_PATH=/usr/bin/chromium node tools/check.mjs --full
node tools/build-preview.mjs
CHROME_PATH=/usr/bin/chromium node tools/test/presentation.mjs
```

`smoke.mjs` 内で全10話、探索の読了条件、救援の失点、決戦の引き分けからの再挑戦、ビーストモードの効果と消費、時間差の終幕、旧セーブの保持、再読込、モデル9種、既存CPU・練習・オンラインモックを確認する。`presentation.mjs` はJSでの疑似クリックではなく、実際のポインター操作で320×568・390×844・1280×800を確認する。

クラウドのChromiumは管理ポリシーで `file://` を開けないため、単一HTMLそのものはHTTPで1ファイルだけ配信し、その他のHTTP要求を遮断して起動・試合開始を検証する。管理ポリシーは変更しない。Pixelなどの実機での重さ、指の操作感、音量バランス、実サービスでの2端末オンライン対戦はTakeの確認事項。

## スマホ配信の追記

スマホはHTTPSのURLで開くPWAを使う。`node tools/build-mobile-preview.mjs` で画像・音声を埋め込んだ `dist/mobile-preview/` と `dist/mobile-preview.zip` を生成する。本番と別の `saboten-apps/baseball-preview` リポジトリの `preview` ブランチをGitHub Pagesで配信済み。確認URLは https://saboten-apps.github.io/baseball-preview/ 。

同一のGitHub Pagesドメインでも本番と混ざらないよう、保存キーを `mobile-preview-` で分け、オンラインルームも別の接頭辞にする。共有URLは確認版自身のパスを使用し、キャッシュ名はサービスワーカーのスコープごとに分ける。タッチ対応ChromiumでAndroidおよびiPhone相当の画面、スワイプ投球、保存領域の分離、キャッシュからのオフライン再起動を検証済み。iPhoneのSafari実機・ホーム画面への実インストールは未確認。

本番リポジトリのPagesソースやmainは変更しない。作業ブランチのソースと生成結果を保存し、確認用リポジトリには `dist/mobile-preview/` の内容だけを反映する。

第8話の覚醒前は投球側で、野球星人がコース・球種に関わらず3球連続でホームランを打つ。3本目の後に覚醒会話・任意動画・意思決定へ進み、打撃側の新しい挑戦へ切り替える。前半の3失点は得点目標へ加算せず、覚醒後1点でクリア。再挑戦は投球からやり直す。`story-opening.mjs` は中央・隅・大きく外れたボール球を実際に投げ、各HRと3本目だけでの覚醒開始を検証する（smoke/story-peaks/story-moviesから使用）。
